מדריך התקנה

כ-2 דקות לכל תוסף. אותם שלבים לשני התוספים.

חזרה לתוספים

התקנה

  1. הורדה: בדף הראשי לוחצים "הורדה" ליד התוסף הרצוי. יורד קובץ ZIP.
  2. חילוץ: לחצן ימני על הקובץ ← "חלץ הכל", ושומרים בתיקייה קבועה. לא למחוק את התיקייה אחר כך – Chrome טוען ממנה את התוסף.
  3. דף התוספים: בשורת הכתובת של Chrome מקלידים chrome://extensions ולוחצים Enter.
  4. מצב מפתח: מפעילים את המתג Developer mode בפינה העליונה של הדף.
  5. טעינה: לוחצים Load unpacked ובוחרים את התיקייה שחולצה – זו שבתוכה נמצא manifest.json.
  6. רענון Gmail: חוזרים ל-Gmail ולוחצים F5.

שימוש

סינון מתקדם

  1. בפינה התחתונה של Gmail מופיע כפתור עם אייקון סינון.
  2. מסמנים את מה שרוצים – אפשר כמה אפשרויות בכל קבוצה.
  3. לוחצים סנן. כדי לשמור את הבחירה, כותבים שם בתחתית החלונית ולוחצים שמור.

הקלטה מצורפת

  1. פותחים כתיבה או "השב". ליד "שליחה" מופיע כפתור 🎤 הקלטה.
  2. בפעם הראשונה מאשרים ל-Chrome גישה למיקרופון.
  3. מדברים, ולוחצים שוב כדי לעצור. קובץ MP3 מצטרף לאימייל.
  4. גזירת מסך (אייקון חיתוך): נפתח כלי הגזירה של Windows, כמו Win+Shift+S. גוזרים אזור, והתמונה נכנסת לבד לגוף האימייל במקום שבו עמד הסמן. בפעם הראשונה Chrome שואל אם לפתוח את כלי הגזירה – מסמנים "תמיד לאפשר".
  5. וידאו מסך (אייקון מצלמה): בוחרים מה להקליט, מדברים תוך כדי, ולוחצים שוב לעצירה. מצטרף ZIP עם הווידאו. מעל כ-2 דקות הקובץ עובר 25MB ו-Gmail ישלח אותו דרך Drive.

משהו לא עובד?

הכפתור לא מופיע ב-Gmail

ב-chrome://extensions לוחצים ⟳ בכרטיס התוסף ומרעננים את Gmail. אם יש בכרטיס כפתור אדום "שגיאות", לוחצים עליו כדי לראות מה קרה.

"Load unpacked" לא מופיע

צריך להפעיל קודם את המתג Developer mode.

"Manifest file is missing"

נבחרה תיקייה שגויה. בוחרים את התיקייה שבתוכה נמצא הקובץ manifest.json.

אין גישה למיקרופון

לוחצים על סמל המנעול ליד הכתובת של Gmail ← מיקרופון ← אפשר. בודקים גם שהמיקרופון מחובר ומוגדר ב-Windows.
